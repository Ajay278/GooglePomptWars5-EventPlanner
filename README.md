## Overview

**Event Planner Studio** bridges high-level creative ideation and rigorous operational planning for multi-stakeholder events. Rather than relying on static checklists or disconnected spreadsheets, the studio provides a cohesive, single-pane dashboard that links:
- **Event Portfolio Directory**: Portfolio-level KPIs, multi-event filtering, and progress tracking.
- **Master Event Brief**: Executive summaries, countdown milestones, and full `.md` master brief export.
- **Dynamic Budget Tracker**: 4-stat KPI financial strip, multi-category allocation breakdown, actuals vs quotes, deposit receipts, and cost-per-guest calculations.
- **Timelines & Run of Show**: Milestone phase countdowns (6 months out to final week) paired with minute-by-minute day-of schedules and one-click `.ics` calendar export.
- **Vendor Directory & Contract Hub**: Status pipeline (Researching → Contacted → Proposal Received → Contract Signed → Deposit Paid → Confirmed), direct phone/email actions, and quote tracking.
- **Personalized Ideas Studio**: Curated signature experiences, custom cocktails, decor accents, and budget-saving tactics generated by Gemini 3.8 Flash.

## Software Architecture & Design Standards

The application adheres strictly to modern software engineering best practices, type safety, and clean architecture principles:

### 1. Separation of Concerns & Clean Layering
```
event-planner-studio/
├── api/                   # Serverless endpoint adaptor (Vercel Serverless Function)
│   └── index.ts
├── src/
│   ├── components/        # Modular UI View Components
│   │   ├── AiPlannerModal.tsx
│   │   ├── BudgetView.tsx
│   │   ├── EventSelector.tsx
│   │   ├── EventsListView.tsx
│   │   ├── Header.tsx
│   │   ├── IdeasInspirationView.tsx
│   │   ├── OverviewView.tsx
│   │   └── TimelineView.tsx
│   ├── data/              # Default initial event seeds & schema fixtures
│   │   └── initialEvents.ts
│   ├── server/            # Express REST Router & Gemini SDK proxy
│   │   └── eventApi.ts
│   ├── types/             # Domain TypeScript interfaces and enumerations
│   │   └── event.ts
│   ├── utils/             # Date math, iCal generators, formatting helpers
│   │   └── dateUtils.ts
│   ├── App.tsx            # Main state controller & tab router
│   ├── index.css          # Tailwind CSS v4 design token import
│   └── main.tsx           # React 19 entry point
├── server.ts              # Full-stack Node/Express dev & production server
└── vite.config.ts         # Vite bundler & proxy configuration
```

### 2. Strict Type Safety
- **No `any` Shortcuts**: Domain models (`FullEventPlan`, `BudgetItem`, `TimelineMilestone`, `VendorItem`, `PersonalizedIdea`) are strictly typed in `src/types/event.ts`.
- **Compile-Time Validation**: Verified through `tsc --noEmit` and Vite production bundling with zero warnings.
- **Schema Validation**: Server endpoints enforce structured JSON responses with explicit property types using Gemini SDK's `responseSchema` specifications.

### 3. Server-Side Secret Isolation (Zero Client Keys)
- Client-side code never accesses or exposes `GEMINI_API_KEY`.
- All AI operations are encapsulated behind server-side REST proxy routes (`/api/events/*`).
- Environment variables are managed cleanly via standard `.env` patterns.

### 4. UI/UX Design System Standards
- **Zero-Pill Discipline**: Avoids redundant, generic visual badges; uses clean, high-contrast text and dot separators (`·`).
- **Tabular Font Hierarchy**: Financial and metric numbers use monospace tabular figures (`font-mono tabular-nums`) to prevent optical jitter during live recalculations.
- **Consistent Currency Standard**: Standardized throughout all calculations, KPI strips, form labels, and Gemini prompts to the Indian Rupee (**₹** / **INR**).
- **Responsive Layout**: Designed for mobile touch targets, tablet viewports, and multi-column desktop monitors.

## API Specifications

### `POST /api/events/generate-plan`
Generates a complete, multi-section master event plan.
- **Request Body**:
  ```json
  {
    "eventType": "wedding | birthday | community | anniversary | corporate_gala",
    "title": "String",
    "date": "YYYY-MM-DD",
    "location": "String",
    "guestCount": 120,
    "targetBudget": 35000,
    "themeStyle": "String",
    "specialRequests": "String"
  }
  ```
- **Response**: `{ "success": true, "plan": FullEventPlan }`

### `POST /api/events/suggest-ideas`
Curates 4 personalized, bespoke event experiences, signature food/drink, decor, and budget-saver tips.
- **Request Body**: `{ "eventType": "...", "themeStyle": "...", "guestCount": 50, "targetBudget": 5000 }`
- **Response**: `{ "success": true, "ideas": PersonalizedIdea[] }`

### `GET /api/health`
Health check endpoint reporting service status and timestamp.

## Resilience & AI Safety Patterns

1. **Timeout Protection**: All Gemini API calls are wrapped in a promise race timeout (`withTimeout(promise, 14000)`). If upstream latency occurs, the system fails gracefully without blocking the client.
2. **Deterministic Fallbacks**: In the rare event of API throttling or model unreachability, the server synthesizes a robust, mathematically balanced event template so user workflows remain uninterrupted.
3. **Structured Output Enforcement**: Enforces `responseMimeType: 'application/json'` paired with strict `responseSchema` definitions to prevent parsing failures.
4. **Local State Persistence**: All user changes, edits, and deletions persist across sessions using `localStorage` synchronization with safety guards.

## Getting Started & Local Development

### 1. Prerequisites
- Node.js >= 20.x
- npm >= 10.x

### 2. Installation
```bash
npm install
```

### 3. Environment Setup
Create a `.env` file from `.env.example`:
```bash
GEMINI_API_KEY="your-gemini-api-key"
PORT=3000
```

### 4. Running the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 5. Automated Testing & Verification
```bash
npm test        # Runs native Node.js test suite across all 14 unit & integration tests
npm run lint    # Runs tsc --noEmit for 100% strict type safety
npm run build   # Produces optimized production bundle in dist/
```
